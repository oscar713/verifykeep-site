Your clients' statements are someone else's life savings. We treat them that way.

VerifyKeep exists to read financial documents — the most sensitive files a firm handles. This page states plainly what we store, who can reach it, and what happens when you leave.

  • Encrypted at rest and in transit

    Every statement file is stored in AWS S3 with server-side encryption keyed by AWS KMS (SSE-KMS). All traffic runs over TLS. There is no path in the application that writes a statement unencrypted.

  • Tenant isolation at the database layer

    Each workspace's data is separated by PostgreSQL row-level security — the database itself refuses cross-workspace reads, not just application code. One firm's statements cannot be returned to another firm's session.

  • MFA required for administrative access

    Workspace administrators must enroll TOTP multi-factor authentication before they can manage members, billing, or retention settings. Platform-operator access requires a separate role plus MFA.

  • You choose how long statements stay

    Retention is a per-client setting: delete after export, keep 30 days, or keep 90 days. Deletion tombstones preserve the audit trail — what was processed and when — without keeping the document itself.

  • Uploads hardened against hostile files

    PDFs containing JavaScript, embedded files, launch actions, or encryption are rejected at inspection. Uploads are rate-limited per user and per workspace, capped at 100 MB and 500 pages, and text extraction runs in a memory- and time-bounded subprocess.

  • How the AI extraction works

    Statement pages are sent to a structured-output API that returns transactions as strict JSON. Under the provider's API terms, API inputs are not used to train models. No statement is ever posted publicly or browsed by a human as part of normal processing.

  • Flagged rows are never hidden

    Rows that fail reconciliation are surfaced for review — never silently dropped or exported. What you export is what the checks proved, and the export carries the verdict.

  • Report a vulnerability

    Email hello@verifykeep.com with "SECURITY" in the subject. We read every report and respond before we ship the fix.

Counted, not claimed: the platform currently runs 545 automated tests, 5 deterministic reconciliation checks, 4 export formats, and per-user plus per-workspace upload limits. Security pages describe intent; tests describe behavior.
