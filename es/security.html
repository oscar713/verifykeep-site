Los estados de cuenta de tus clientes son los ahorros de otra persona. Los tratamos así.

VerifyKeep existe para leer documentos financieros — los archivos más sensibles que maneja una firma. Esta página dice claramente qué guardamos, quién puede acceder y qué pasa cuando te vas.

  • Cifrado en reposo y en tránsito

    Cada archivo de estado de cuenta se guarda en AWS S3 con cifrado del lado del servidor mediante AWS KMS (SSE-KMS). Todo el tráfico usa TLS. No existe ninguna ruta en la aplicación que escriba un estado de cuenta sin cifrar.

  • Aislamiento de tenants a nivel de base de datos

    Los datos de cada espacio de trabajo se separan con seguridad a nivel de fila de PostgreSQL — es la propia base de datos la que rechaza lecturas entre espacios, no solo el código de la aplicación. Los estados de cuenta de una firma nunca pueden devolverse a la sesión de otra.

  • MFA obligatorio para el acceso administrativo

    Los administradores del espacio deben activar autenticación TOTP multifactor antes de gestionar miembros, facturación o retención. El acceso de operador de plataforma requiere un rol separado además de MFA.

  • Tú decides cuánto tiempo se conservan los estados

    La retención es una opción por cliente: eliminar tras la exportación, conservar 30 días o conservar 90 días. Las eliminaciones dejan una marca que conserva el rastro de auditoría — qué se procesó y cuándo — sin guardar el documento.

  • Cargas blindadas contra archivos hostiles

    Los PDF que contienen JavaScript, archivos incrustados, acciones de lanzamiento o cifrado se rechazan en la inspección. Las cargas tienen límite de frecuencia por usuario y por espacio, un máximo de 100 MB y 500 páginas, y la extracción de texto corre en un subproceso con límites de memoria y tiempo.

  • Cómo funciona la extracción con IA

    Las páginas del estado se envían a una API de salida estructurada que devuelve las transacciones como JSON estricto. Según los términos de API del proveedor, las entradas no se usan para entrenar modelos. Ningún estado de cuenta se publica ni es leído por una persona como parte del procesamiento normal.

  • Las filas marcadas nunca se ocultan

    Las filas que no superan la conciliación se muestran para revisión — nunca se descartan ni se exportan en silencio. Lo que exportas es lo que las verificaciones probaron, y la exportación lleva el veredicto.

  • Reportar una vulnerabilidad

    Escribe a hello@verifykeep.com con "SECURITY" en el asunto. Leemos cada reporte y respondemos antes de publicar la corrección.

Contado, no afirmado: la plataforma ejecuta hoy 545 pruebas automatizadas, 5 verificaciones deterministas de conciliación, 4 formatos de exportación y límites de carga por usuario y por espacio de trabajo. Las páginas de seguridad describen intención; las pruebas describen comportamiento.
